# 地表材质与体积云

## 当前云与云影版本

云已改为自定义空间着色器中的三维密度积分，保留 Godot 4.6 的 GL Compatibility 渲染模式。
云形采用连续的多尺度天气场：低频形成大片相连的云与开阔空白，中高频形成大小不一的碎云和沿风向延伸的薄云丝；不再按单元摆放独立云团。主体分为下层云群和较高的疏散碎云，分别使用不同的高度、云形、速度和风向，并共享缓慢变化的湿润区域分布。
完整云场的厚度不随镜头缩放变化，密度会随时间连续演化，地面云影始终按这份完整云场计算。近景仅在云本体的显示中压薄、减淡，方便操作；远景恢复完整厚云，允许局部遮挡战场。太阳采样始终使用完整世界云场，上层云能随太阳方向遮暗下层云。另有只用于远景背景的高空云丝，在接近最大视角时渐显。
本次仅替换云与云影；地形固有色、草风、地表分档光照、雾、太阳、机甲与战斗代码保持原样。
下列说明覆盖本文后面的旧版云参数、平面尺寸和采样成本说明；旧段落保留作此前地表材质的说明。

- `cloud_field.gdshaderinc`：两段世界高度中的云团分布、三维密度、太阳方向透光和地面云影积分，云本体与接收材质共用。地面云影叠加两层的光学厚度后计算透射率。
- `cloud_base_noise.tres` / `cloud_volume_noise.tres`：Godot 本地生成的两份 96×96×96 无缝三维噪声，分别提供连续的 Perlin 主体和 cellular 云泡、边缘侵蚀。水平天气场只控制覆盖，云体由三维密度形成，不再将二维云量直接当成云顶高度。`cloud_noise.tres` 的四倍频 Perlin 噪声负责大片分布、空白和丝缕。
- `CloudWeather.gd`：在场景进入树时选取本局天气原点，让云本体和全部接收材质使用同一个布局；默认每次运行随机，非零 `weather_seed` 可重现布局。主世界在生成地块、单位材质副本前设置模板；独立预览同步内联材质。同时创建共享的 256×256 太阳透射缓存。
- `cloud_sunlight.gdshader`：在二维 SubViewport 中按完整世界云场生成透射率，R/G 保存下层与上层的地面遮光，B 保存上层对下层云的透光。缓存以太阳光线在 y=0 平面的交点索引，三种接收高度共用同一份纹理，不是将云影直接贴到屏幕上。
- `cloud_layer.gdshader`：按相机视线采样云层，再沿太阳方向积分遮光，以透射率累积颜色与透明度。视线消光和太阳消光分开调节；太阳采样向近处集中，使厚云内也保留受光面、灰部和柔和过渡。视线分别积分上、下两段云体，再按前后顺序合成，不在中间空隙浪费步数。下层受光同时考虑自身和上层遮光，阴影方向由太阳决定。
- 主场景和 `StylePreview.tscn` 的 `CloudLayer` 都是相机下的 2×2 全屏 QuadMesh。网格只提供绘制覆盖，实际云底高度和厚度由共享参数决定，云的位置不会跟随镜头移动。
- 使用场景深度重建视线，支持当前正交镜头，并在不透明物体表面停止积分。深度重建采用 Compatibility 的 reversed-Z / OpenGL NDC。
- 云的视线起点沿原视线移到相机世界高度的水平面上。正交镜头的近裁剪面在世界中倾斜，直接从该面开始会把高处云层和背景云丝在画面下方横向截断；统一高度可避免平移时云经过截断线突然消失。场景深度仍用于停止积分，相机低于云层时仍会退出该层。
- 当前地块顶面约为 y=0.08；近景 y=0.18～0.5 的凸起表面会逐渐减淡云遮挡，以保留机甲轮廓。远景逐步取消这一减淡，允许厚云遮住单位。该高度阈值按当前单位模型设置，之后修改地形高度或单位尺寸时应一起复核。
- 云材质的透明绘制优先级为 -10，让原有路径和攻击提示在云之后绘制。
- 仅云本体从正交投影矩阵读取镜头大小。在 size 20～40 之间平滑取消近景的显示淡化，恢复完整云层；地面材质不读取这个缩放值。
- 近景显示会压缩云本体的高度采样，同时降低可见采样密度与透明度倍率。云影始终采样原始厚云，不会随缩放加深、变宽或变形；云与云影仍按共同的风速移动。
- 大轮廓、内部三维起伏、外围云丝以不同速度和方向连续演化；关闭整体漂移后仍会逐渐凝聚、消散。演化发生在共用密度场中，云影也随云形变化。上层风向相对主风偏转约 12.6°，速度为 1.35 倍；每层内部还有小幅高度风切变。
- 高空云丝是美术背景：size 34～40 平滑渐显，只在深度缓冲的背景空白处显示，并衬在两层体积云之后，不叠加到棋盘、单位和战术提示上。它不属于实体天气云场，不参与地面或云层间的遮光，显隐不会改变世界光照。
- 扩大天气场边缘的过渡范围，以圆滑的密度过渡替代直接切到零的侵蚀边界；减弱细小侵蚀和云丝亮边，保留厚云核心。
- 远景仅在可见采样中降低小尺度密度对比，云影始终使用完整细节。默认使用冷白受光色和灰蓝阴影补色，避免以厚度直接映射成纯白；同时保留散射补光，暗部不直接变黑。

共享参数仍分别属于云材质和接收材质；默认值集中在 include 中。
如果在 Inspector 覆盖云形、风向、高度或太阳方向，请同步 `cloud_layer.tres`、`low_poly.tres` 和预览材质。草风方向参数保持原名和默认值，已移至共享 include；草风的强度、速度、弯曲与分布公式保持原样。
调节太阳方向时仍需与 `Sun` 一致，本次没有引入自动昼夜或天气控制器。
分布由连续噪声生成。场景的 `CloudWeather.weather_seed = 0` 表示每次启动选取新布局；设置为非零整数则重现同一布局，需结合相同的运行时间和镜头比较。基础噪声资源的种子保持固定，以复用纹理生成结果；每局随机的是世界天气原点。云场在运行中随风漂移并连续演化，不逐帧随机重置。

太阳透射缓存每帧在上下两层各使用 4 个高度样本估算接收面阴影，并另取 3 个上层样本提供层间遮光。地面与机甲通过双线性过滤查询缓存；它是同一密度场的低采样近似，并非引擎方向光的原生体积阴影。
默认缓存覆盖 y=0 光线交点平面的 (-48, -48) 到 (80, 80) 区域。范围外或位于云层内部的接收面继续直接积分，避免镜头移动后截断云场。缓存与实体云场共享时间、布局、风向和形态参数，不读取镜头缩放。两层云各自的内部遮光仍沿实际太阳光线积分。运行时若通过代码调节共用云形或风参数，也需同步 `CloudWeather` 的 `_sunlight_material`；场景初始化会从云材质复制已有覆盖值。
本体使用实际三维密度积分，不使用 Godot 原生体积雾、计算着色器或额外插件。
相机拉近到云底以下时，视线不会再经过高处云层，云本体自然离开画面；地面仍接收云影。
画面成本高于此前的单层体积云，可调节 `cloud_steps` 和 `cloud_upper_steps`；未对不同硬件做性能承诺。

## 文件与接入

- `low_poly.gdshader`：不透明地块、棋子、建筑共用的面光照。
- `cloud_layer.gdshader`：半透明高空云层。
- `cloud_field.gdshaderinc`：两者共用的世界坐标云场。
- `low_poly.tres` / `cloud_layer.tres`：可在 Inspector 中调参的模板。
- `cloud_noise.tres`：共享的 512×512 无缝双倍频 Perlin 噪声，仅资源生成时计算。
- `StylePreview.tscn`：独立预览，编辑器中打开后按 F6。

当前地块和棋子的运行时材质已通过 `world/StylizedMaterials.cs` 接入；保留原来的地形颜色、敌我颜色与选中高亮。攻击、路径和格子描边维持原有信息材质。其他不透明模型可直接挂 `low_poly.tres`，修改颜色时先复制材质，不必复制 shader 或噪声。

所有风格参数应在 `low_poly.tres` 中统一设置；材质工厂复制模板，只覆盖 `base_color` 和 `selection_glow`。修改模板后重新运行场景，已创建的副本不会自动追踪模板的新参数。

## 面光照与配色

| 参数 | 默认值 | 调整方式 |
| --- | --- | --- |
| `base_color` | 草绿 | 物体固有色；棋子/地块由原 C# 颜色控制 |
| `ambient_color` | 冷灰蓝 | 阴面补色，避免纯黑；与暖色棋子形成冷暖关系 |
| `ambient_strength` | 0.48 | 阴面亮度，推荐 0.3–0.6 |
| `direct_strength` | 0.85 | 方向光贡献，推荐 0.6–1.2 |
| `light_steps` | 3 | 光照档位，2 更硬朗，4–5 更温和 |
| `selection_glow` | 黑 | 选中补光，由 C# 控制 |

片元导数重建每个三角面的几何法线，不依赖模型平滑法线；在单个方向光下，同方向的平面具有一致的基础光照。刻意保留云影、真实投影和雾的连续变化，因此开启这些效果后，不承诺整面每个像素完全同色。严格纯色面可将 `cloud_shadow_strength`、`fog_strength` 归零并关闭灯光阴影。

保留一个 `DirectionalLight3D`，可直接调灯光颜色、能量和阴影。环境光在 shader 内统一计算，不叠加 WorldEnvironment 的环境光。默认无高光，无纹理细节。不要再叠加多个方向光，否则会累加亮度。

## 巨大尺度的云与云影

世界场景已预放置 `CloudLayer` 平面，高度 7，尺寸 100×100，覆盖当前棋盘；它不投射原生阴影。地面和棋子沿太阳方向投影采样同一云场，得到跨物体连续的柔和云影，不需要第二个阴影贴图。

以下参数来自共享 include，但仍是各材质独立的 uniform。请在 `low_poly.tres` 和 `cloud_layer.tres` 中设置相同值：

| 参数 | 默认值 | 调整方式 |
| --- | --- | --- |
| `cloud_scale` | 0.035 | 越小云块越巨大；推荐 0.015–0.05 |
| `cloud_velocity` | (0.22, 0.09) | 世界单位/秒；减半会更沉稳，不是 UV 速度 |
| `cloud_warp` | 0.22 | 第二次采样扰动轮廓，推荐 0.1–0.35 |
| `cloud_coverage` | 0.46 | 越大云覆盖越多 |
| `cloud_softness` | 0.18 | 密度阈值过渡，越大云缘/云影越柔 |
| `cloud_height` | 7 | 接收面到云层的投影距离；同步 CloudLayer 的全局 Y |
| `sun_direction` | (-0.287, 0.819, 0.497) | 从表面指向太阳的世界方向；对应当前 Sun 的全局正 Z 轴 |

`sun_direction` 需要与真实 Sun 同步，当前不自动跟踪灯光旋转。只要 Y 为正，方向向量不必归一化，投影使用 XZ/Y 比值。修改灯光时将其全局 Basis.Z 写到两份材质；光照本身仍由真实灯光驱动。

| 独立参数 | 所属材质 | 调整方式 |
| --- | --- | --- |
| `cloud_shadow_strength` | low_poly | 默认 0.32；0 关闭，推荐不超过 0.45，保留阴面环境补光 |
| `cloud_opacity` | cloud_layer | 默认 0.13；推荐 0.06–0.18，避免遮住战术信息 |
| `cloud_color` | cloud_layer | 云本体颜色，默认偏冷白 |
| `edge_fade` | cloud_layer | 平面边缘淡出范围，默认 UV 0.15 |

噪声是无缝贴图，最终仍会周期重复，但大尺度平移加低频扰动可避免短时间机械循环；不是非周期体积模拟。`TIME` 使用 Godot 默认回绕时间，长时间运行可能在回绕时跳变。云平面有限大：扩大棋盘时扩大平面并重新居中；接收面云影不受平面边缘淡出影响，应保证可玩区域位于其内部。

## 可选增强

| 参数 | 默认值 | 调整方式 |
| --- | --- | --- |
| `fog_color` | 冷灰青 | 远处逐渐褪向该颜色，建议接近背景色 |
| `fog_start` / `fog_end` | 35 / 95 | 相机空间距离起止；正交相机也生效，end 必须大于 start |
| `fog_strength` | 0.16 | 轻微大气透视；0 关闭，推荐 0.05–0.2 |
| `vertex_ao_strength` | 0 | 读取模型顶点色 R 作为烘焙 AO，0 黑、1 白；无顶点 AO 时保持 0 |

雾是材质内的距离褪色，不采样深度、不影响 UI/战术预览、不是体积雾。顶点 AO 只能表达烘焙遮蔽，不会随棋子移动生成接触阴影；当前接触处依靠 Sun 的真实阴影。GL Compatibility 不支持原生 SSAO：如需动态 SSAO，需切换 Forward+ 并在 WorldEnvironment 开启 SSAO，该增强不属于此低成本方案。

## 性能与建议顺序

每个不透明片元两次共享纹理采样；云平面也两次，无屏幕颜色/深度读取、无 raymarch、无逐帧 C# 更新。噪声资源共享，但棋子和地块仍各有材质副本，不承诺合批。云透明平面会产生一次较大面积的透明过绘；可缩小平面或隐藏节点。仅将云影强度设为 0 并不保证驱动消除采样。

先关闭雾和云，确定固有色、环境强度和三档方向光；再开低强度云影，最后开极轻的云本体与雾。云块跨度大于多个格子、移动远慢于棋子，尺度感最稳定。不要靠过强 AO、浓雾或高不透明云遮挡棋盘。
