# 地表材质与体积云

## 云与云影

云使用自定义着色器按世界坐标积分三维密度，保留 Godot 4.6 的 GL Compatibility 渲染模式。
云形采用连续的多尺度天气场：低频形成大片相连的云与开阔空白，中高频形成大小不一的碎云和沿风向延伸的薄云丝。主体分为下层云群和较高的疏散碎云，分别使用不同的高度、云形、速度和风向，并共享缓慢变化的湿润区域分布。
完整云场的厚度不随镜头缩放变化，密度会随时间连续演化，地面云影始终按这份完整云场计算。近景仅在云本体的显示中压薄、减淡，方便操作；远景恢复完整厚云，允许局部遮挡战场。太阳采样始终使用完整世界云场，上层云能随太阳方向遮暗下层云。另有只用于远景背景的高空云丝，在接近最大视角时渐显。
比例按六边形边长 1 km、场景单位 1 km 标定，高度以棋盘逻辑地面 y=0 为基准。低云占据 1.5～2.3 km，中云占据 4.0～4.7 km，两层净空 1.7 km；背景云丝映射高度约 9 km。低、中云的密度倍率分别为 4 和 3.25，控制光学厚度，使远景保留厚云遮挡和内部明暗。

- `cloud_field.gdshaderinc`：两段世界高度中的云团分布、三维密度、太阳方向透光和地面云影积分，云本体与接收材质共用。地面云影叠加两层的光学厚度后计算透射率。
- `cloud_base_noise.tres` / `cloud_volume_noise.tres`：Godot 本地生成的两份 96×96×96 无缝三维噪声，分别提供连续的 Perlin 主体和 cellular 云泡、边缘侵蚀。水平天气场只控制覆盖，云体由三维密度形成。`cloud_noise.tres` 的四倍频 Perlin 噪声负责大片分布、空白和丝缕。
- `CloudWeather.gd`：在场景进入树时选取本局天气原点，让云本体和全部接收材质使用同一个布局；默认每次运行随机，非零 `weather_seed` 可重现布局。主世界在生成地块、单位材质副本前设置模板；独立预览同步内联材质。通过统一的材质与视口初始化函数创建 512×512 云量分布缓存、256×256 太阳透射缓存和云本体视线缓存。三份缓存默认按每秒 20 次更新，不限制游戏帧率。
- `cloud_weather.gdshader`：按世界坐标计算两层云的水平覆盖和云丝包络，RG/BA 分别保存上下两层。视线、云内光照和地面云影复用这份缓存，减少每个三维密度采样点的重复噪声计算。三维云泡、侵蚀和光线积分保持原有采样数；内部演化和风速不变，仅减少计算次数。
- `cloud_sunlight.gdshader`：在二维 SubViewport 中按完整世界云场生成透射率，R/G 保存下层与上层的地面遮光，B 保存上层对下层云的透光。缓存以太阳光线在 y=0 平面的交点索引，三种接收高度共用同一份纹理，不是将云影直接贴到屏幕上。
- `cloud_optics.gdshaderinc`：共用的视线积分和显示参数。按相机视线采样云层，再沿太阳方向积分遮光，以透射率累积颜色与透明度。视线消光和太阳消光分开调节；太阳采样向近处集中，使厚云内也保留受光面、灰部和柔和过渡。上下两段分别积分，不在中间空隙浪费步数。下层受光同时考虑自身和上层遮光，阴影方向由太阳决定。
- `cloud_view.gdshader`：在云专用的二维 SubViewport 中分别计算上下层的预乘颜色与透明度，存于一张纹理的上、下半区。默认每层有效分辨率为主视口的 75%，四周再多算 10% 的平移余量。它只渲染云，不包含地形、棋子或界面。
- `cloud_layer.gdshader`：每个游戏画面帧按当前正交视线重新投放云缓存、读取当前场景深度、合成上下层并执行近景单位保护。因此云计算降频后，镜头平移、棋子和界面仍按游戏帧率显示。缩放、旋转、窗口尺寸改变或大幅平移会立即刷新视线缓存；缓存余量外的像素直接积分，不截断云层。物体表面进入某层云的高度时，该像素也直接积分并在真实深度停止，避免用整层缓存盖住云内的高物体。
- 主场景和 `StylePreview.tscn` 的 `CloudLayer` 都是相机下的 2×2 全屏 QuadMesh。网格只提供绘制覆盖，实际云底高度和厚度由共享参数决定，云的位置不会跟随镜头移动。
- 使用场景深度重建视线，支持当前正交镜头，并在不透明物体表面停止积分。深度重建采用 Compatibility 的 reversed-Z / OpenGL NDC。
- 云的视线起点沿原视线移到相机世界高度的水平面上。正交镜头的近裁剪面在世界中倾斜，直接从该面开始会把高处云层和背景云丝在画面下方横向截断；统一高度可避免平移时云经过截断线突然消失。场景深度仍用于停止积分，相机低于云层时仍会退出该层。
- 当前地块顶面约为 y=0.08；近景 y=0.18～0.5 的凸起表面会逐渐减淡云遮挡，以保留机甲轮廓。远景逐步取消这一减淡，允许厚云遮住单位。该高度阈值按当前单位模型设置，之后修改地形高度或单位尺寸时应一起复核。
- 云材质的透明绘制优先级为 -10，让原有路径和攻击提示在云之后绘制。
- 仅云本体从正交投影矩阵读取镜头大小。size 8～14 由完全淡出过渡到轻薄云层，size 20～40 再平滑取消近景淡化，恢复完整云层；地面材质不读取这个缩放值。最近视角会在体积采样前退出云本体绘制，云影缓存仍按完整云场更新。
- 近景显示会压缩云本体的高度采样，同时降低可见采样密度与透明度倍率。云影始终采样原始厚云，不会随缩放加深、变宽或变形；云与云影仍按共同的风速移动。
- 大轮廓、内部三维起伏、外围云丝以不同速度和方向连续演化；关闭整体漂移后仍会逐渐凝聚、消散。演化发生在共用密度场中，云影也随云形变化。上层风向相对主风偏转约 12.6°，速度为 1.35 倍；每层内部还有小幅高度风切变。
- 高空云丝是美术背景：size 34～40 平滑渐显，只在深度缓冲的背景空白处显示，并衬在两层体积云之后，不叠加到棋盘、单位和战术提示上。它不属于实体天气云场，不参与地面或云层间的遮光，显隐不会改变世界光照。
- 天气场边缘使用圆滑的密度过渡；细小侵蚀和云丝亮边较弱，厚云核心保留。
- 远景仅在可见采样中降低小尺度密度对比，云影始终使用完整细节。默认使用冷白受光色和灰蓝阴影补色，避免以厚度直接映射成纯白；同时保留散射补光，暗部不直接变黑。

云场默认参数位于 `cloud_field.gdshaderinc`，视线积分和采样参数位于 `cloud_optics.gdshaderinc`，最终透明度、单位保护和背景云丝参数位于 `cloud_layer.gdshader`。共享的云场参数仍分别属于云材质和接收材质。
如果在 Inspector 覆盖云形、风向、高度或太阳方向，请同步 `cloud_layer.tres`、`low_poly.tres` 和预览材质。草风方向参数保持原名和默认值，已移至共享 include；草风的强度、速度、弯曲与分布公式保持原样。
调节太阳方向时仍需与 `Sun` 一致，本次没有引入自动昼夜或天气控制器。
分布由连续噪声生成。场景的 `CloudWeather.weather_seed = 0` 表示每次启动选取新布局；设置为非零整数则重现同一布局，需结合相同的运行时间和镜头比较。基础噪声资源的种子保持固定，以复用纹理生成结果；每局随机的是世界天气原点。云场在运行中随风漂移并连续演化，不逐帧随机重置。

太阳透射缓存每次更新在上下两层各使用 4 个高度样本估算接收面阴影，并另取 3 个上层样本提供层间遮光。地面与机甲通过双线性过滤查询缓存；它是同一密度场的低采样近似，并非引擎方向光的原生体积阴影。
默认太阳缓存覆盖 y=0 光线交点平面的 (-48, -48) 到 (80, 80) 区域；云量缓存复用同一范围，但直接以三维采样点的 xz 索引。太阳缓存范围外或位于云层内部的接收面继续直接积分，云量缓存范围外继续使用原噪声公式，不把范围外的云清空。云量缓存使用双线性插值，会带来少量数值近似，不减少云的视线或自遮光采样次数。
云量和太阳缓存与实体云场共享时间、布局、风向和形态参数，不读取镜头缩放。云专用时钟通过一张共享的 1×1 浮点纹理传给材质副本，默认每 0.05 秒推进到实际累计时间；云本体、云影以及缓存范围外的直接计算使用同一时间。草风仍使用原生 `TIME`，不跟着云降频。两层云各自的内部遮光仍沿实际太阳光线积分。运行时若通过代码调节共用云形或风参数，也需同步 `CloudWeather` 的 `_weather_material`、`_sunlight_material` 和 `_view_material`；场景初始化会从云材质复制已有覆盖值。
本体使用实际三维密度积分，不使用 Godot 原生体积雾、计算着色器或额外插件。
当前相机最近时约高 4.6 km，仍位于低云上方，所以近景操作保护使用显式缩放淡出，不依赖相机降到云底以下；地面仍接收完整云影。后续若将相机移到某层云底以下，向下的视线也会自然跳过那层云。
云本体计算成本随缓存分辨率、更新次数及 `cloud_steps` / `cloud_upper_steps` 增加。
项目帧率、VSync 和其他项目设置沿用本开发分支起点的主支设置；云模块不设置游戏帧率上限。云更新频率由场景 `CloudWeather.cloud_update_fps` 控制，默认 20；云本体缓存的分辨率倍率由 `cloud_resolution_scale` 控制，默认 0.75。两者只影响云模块，不改变云速、物理频率或其他画面的帧率。最近视角跳过云本体缓存，云影仍按完整厚度更新。性能对比需包含主视口和三份缓存的计算开销；静止或常规平移时云计算降频，连续缩放或旋转会增加云本体的刷新次数。帧率上限、VSync 和显卡自动降频会影响测量结果。

参考项目、固定版本与 MIT 原文见 [CLOUDS_LICENSES.md](CLOUDS_LICENSES.md)。
薄云形态参考 NASA 的[卷云羽流卫星影像](https://science.nasa.gov/earth/earth-observatory/cirrus-plume-over-the-sierra-nevadas-6984/)；没有将卫星照片用作游戏贴图。

## 地表、棋子与材质接入

`low_poly.gdshader` 为山地、水面、棋子和建筑提供分档面光照、云影和轻雾。Grass 地块使用下文的 `grassland.gdshader`。主世界通过 `world/StylizedMaterials.cs` 选择对应模板并复制材质，覆盖对象固有色和选中补光；非草地对象继续使用原模板。地形与单位颜色由各自的 C# 代码提供，攻击提示、路径和描边使用原有信息材质。

其他不透明模型可挂 `low_poly.tres`，需独立调色时复制材质即可，噪声资源继续共享。`StylePreview.tscn` 的地面使用 `grassland.tres`，棋子保留内联的原材质，在编辑器中打开后按 F6 可独立预览；`CloudWeather` 会给这些材质绑定同一份天气、云影和时钟。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `base_color` | (0.48, 0.68, 0.28) | 材质默认草绿；运行时由地块或单位覆盖 |
| `ambient_color` / `ambient_strength` | (0.70, 0.79, 0.88) / 0.32 | 阴面补色与环境补光强度 |
| `direct_strength` / `light_steps` | 0.65 / 3 | 直接光强度与面光照档数 |
| `selection_glow` | 黑 | 由 C# 设置的选中补光 |
| `fog_color` | (0.62, 0.78, 0.88) | 远处的大气褪色 |
| `fog_start` / `fog_end` / `fog_strength` | 35 / 95 / 0.07 | 相机空间距离中的雾起止与最大强度 |
| `vertex_ao_strength` | 0 | 顶点色 R 通道作为烘焙遮蔽的强度 |

修改模板后重新运行场景，已生成的材质副本不会自动追踪模板的新参数。当前 Grass 地块的风动全部由专用材质计算，原材质中已停用的颜色风带及其专用参数已移除；云场共用的 `grass_wind_direction` 仍保留。

光照由片元导数重建三角面的几何法线，并对方向光贡献分档。云影、原生物体投影和雾仍连续变化，因此一个三角面上的最终像素可能不同色。场景使用一个 `DirectionalLight3D`，太阳参数需与云材质同步；环境补光由 shader 计算，未叠加 WorldEnvironment 的环境光，也没有镜面高光。

雾只按相机空间距离褪色，不采样深度，不属于体积雾。顶点遮蔽默认关闭，启用后也只读取烘焙数据；动态物体投影由场景的方向光提供。

## 湿季草原

`grassland.gdshader` / `grassland.tres` 只用于 Grass 地块和美术预览地面。地表以世界 xz 坐标采样，邻格共用连续的颜色与风动分布，不改变六边形网格高度、地形类型、碰撞和移动规则。雨季草原的配色与笔触来自生图制作的 [grassland_canopy.png](textures/grassland_canopy.png)，采用成片草色和冷暖变化；生成来源、完整提示词及使用限制见 [素材说明](textures/grassland_canopy.md)。`Tile.GrassColor` 作为乘法调色，默认轻微偏冷，收住素材中的黄绿色。旧版遍布地面的枯草、湿土、碎斑纹理与细节法线已删除。

草地使用两张共享纹理。草冠图源文件为 1254×1254，导入时限制到 1024 并生成 mipmap。材质分两次读取同一张图：64 km 跨度的第 4 级 mip 只提供平缓色块，较小尺度的镜像采样提供很弱的笔触明暗，避免将微细笔触放大为大片斑点。`grass_land_noise.tres` 为 256×256 的单倍频 Perlin 分布，启用无缝平铺和 mipmap，仅用于阵风形状。每片元合计三次草地纹理采样，云影沿用已有查询。不新增草叶实例、运行时逐草物理、渲染视口或体积积分循环。

草风与云共用 `grass_wind_direction`，地面阵风速度独立标定；草层受光仍按原生 `TIME` 连续更新，不跟随云的 20 次/秒时钟。阵风使用柔和的前缘和较长的恢复段，沿途有强弱和消散，连续改变等效草冠朝向、叶片受光与宽高光，让默认战术视距能够辨认传播过程。地表固有色不随风平移。光照采用连续漫反射与简化的宽高光，高粗糙度控制高光宽度；它不是逐叶片或完整的物理植被模型。云影同时衰减直接漫反射和高光，环境补光保留。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `base_color` | (0.86, 0.96, 1) | 草冠图的乘法调色，运行时由 `Tile.GrassColor` 覆盖 |
| `grass_texture_span` | 64 | 草冠图的世界跨度，单位 km；当前棋盘与预览地面均未跨越纹理重复边缘 |
| `grass_wind_speed` | 0.085 | 阵风传播的视觉速度，单位 km/s，按战术镜头标定，不代表实测风速 |
| `grass_wind_strength` | 0.75 | 草冠朝向与受光的响应强度，0 可静止比较 |
| `grass_wind_spacing` / `grass_wind_width` | 4.8 / 0.85 | 阵风间距与基础恢复段长度，单位 km |
| `grass_sheen_strength` | 0.075 | 草冠宽高光强度 |
| `direct_strength` / `ambient_strength` | 1 / 0.35 | 连续直接光和环境补光强度，仅属于草地材质 |

正交相机缩放时保留色差与阵风的世界尺度，较远视角继续保留宽阔阵风和云影。由于已去掉细碎纹理与法线，不再需要旧版的近远细节分支。采样使用 mipmap 过滤。

实现参考方向：[GPU Gems 2 的风动与远处植被明暗](https://developer.nvidia.com/gpugems/gpugems2/part-i-geometric-complexity/chapter-1-toward-photorealism-virtual-botany)、[Terrain3D 的大尺度颜色与材质分层](https://terrain3d.readthedocs.io/en/stable/docs/shader_design.html)、[HTerrain 的远景整体颜色图](https://hterrain-plugin.readthedocs.io/en/latest/#global-map)。本模块是针对现有平坦棋盘的独立实现，未引入这些地形插件。

## 调参与成本

先用地表材质确定固有色、环境补光和直接光，再调云场、云体显示和云影。云体远近淡化与完整云场的厚度、投影是独立参数，调近景操作遮挡时不必改变物理云厚。

云量、太阳透射和云本体视线缓存分别有一个专用 SubViewport，均复用同一份云场和噪声资源。主视口每帧合成云体，并查询当前物体深度；缓存范围外和进入云层的接收面保留直接积分。它们是当前效果和遮挡正确性所需的计算路径。

本实现使用 Godot 的空间与 CanvasItem 着色器，不依赖原生体积雾、计算着色器或额外插件。地块、棋子仍各自使用材质副本，不能仅由共享噪声推断其绘制已合批。性能测量需同时记录主视口、三份缓存、分辨率、VSync、游戏帧率与云更新频率。
