# 雨季草原独立样区

在 Godot 中打开 `GrasslandStudy.tscn`，按 F6 运行当前场景。F5 仍运行原游戏。这里用于比较缓坡、植被疏密和草冠风动，尚未替换棋盘地形，也没有接入地图存储、碰撞、单位贴地或寻路。

## 观察方式

- 滚轮缩放，右键拖动；镜头沿用游戏的正交投影、35.264° 俯角和 45° 朝向。
- 按 G 显示边长 1 km 的六边格。格线沿同一高度函数生成，可以观察坡面起伏。
- 按空格暂停／继续草冠风动，云场继续运行。
- 按 1／2／3 切到游戏对应的 8／20／40 镜头尺寸；R 回到样区默认的 12。

地表展示范围为 40×40 km，默认镜头观察中心一带；最大缩放时会看到这块有限样区的边界。样区平移到现有棋盘的中心附近，与云场共用世界坐标；它没有读取或保存游戏地图。

## 景观与受风方式

`StudyTerrain.gd` 定义缓坡和弯曲的浅洼，用固定的大形状组织地貌，再叠加较弱的连贯变化。浅洼的草更长、更密，开阔坡面的草更短、更疏；稀疏处也保留绿色植被。几何只在进入场景时生成一次，192×192 个网格单元共 73,728 个三角形，地面为一个绘制面。

`study_canopy.png` 是按植被配色布局及原概念图生成的美术资产。[生成记录](study_canopy.md)保存了用途、约束和完整提示词；`colour_layout.png` 保留了输入布局。新素材提供主色块和笔触，原有 `grassland_canopy.png` 仅提供低幅度的细小纹理，细节主要集中在密草区。地形法线、植被控制图与美术贴图分别提供受光方向、草丛响应和固有色。

`grassland_study.gdshader` 保持地形法线稳定，分别计算直立草冠和伏倒草冠的受光，再根据阵风、草高和草丛分布混合两类响应。短草响应较弱，长草的伏倒比例较高；空间差异打断阵风的整齐边界。高光沿用较弱的宽反射，并随草丛分布变化，风不会额外加亮一条高光带。日照采用轻微的对比曲线，便于在现有高太阳角度下辨认缓坡。

风速参数为 0.085 km/s，用于当前高空镜头的视觉节奏，不是当地气象风速或完整植被力学模拟。风只改变草冠受光，不滚动美术贴图，也不改变地形顶点。

## 资源与重烘焙

运行时读取两张 1024×1024 的线性数据图，不逐帧求地形噪声或重建贴图：

| 资源 | 内容 |
| --- | --- |
| `vegetation.png` | R 覆盖度、G 相对草高、B 草丛方向／响应差异、A 草丛覆盖变化 |
| `surface_normals.png` | 来自同一高度数据及弱草冠起伏的世界空间 XYZ 法线，以 `[0,1]` 编码 |
| `study_canopy.png` | 新生成的草冠主色资产；导入到 1024，启用 mipmap |
| `colour_layout.png` | 生图输入布局，只用于美术制作，不由运行材质加载 |

修改 `StudyTerrain.gd` 后，使用项目当前 Godot 执行下面的离线脚本，并让编辑器重新导入 PNG。若更改了景观布局，还应同步修订美术资产；脚本不会自行调用生图服务。

```sh
godot --headless --path . --script res://shaders/grassland_study/BakeStudy.gd
```

这个命令只改写样区自己的两张数据图和配色布局，不会替换 `study_canopy.png`。数据图保留线性采样、mipmap 和无损导入，不使用切线空间法线图的压缩转换。

太阳和云影沿用现有资源。样区实例在本地把自己的材质绑定到 `CloudWeather` 的时钟、天气和太阳透射缓存；本次没有修改 `CloudWeather.gd`、原草原材质、主游戏场景、项目设置或 C# 业务代码。

## 本机验证记录

2026-10-20 在隔离副本使用当前本机 Godot 4.6.3 Mono、.NET SDK 8.0.426、GL Compatibility 和 RTX 3060 Laptop 验证，分辨率为 1920×1080。使用工作区原有的本机 SDK 声明差异；仓库已提交的 SDK 声明仍为 4.6.1，本轮没有修改它。编译 0 警告、0 错误，资源导入及实际运行成功；地形／法线对应、原云缓存与时钟绑定、正交镜头、格线切换和风动启停共 8 项检查通过。离线烘焙可逐字节重现两张数据图与配色布局。

同一进程冻结云缓存，对比旧平地与本样区。每组采集 180 帧，帧率上限保持 0、VSync 保持启用。以下 GPU 数值只包含主视口绘制，不包含云缓存生成；旧版使用两三角形平面，本样区包含实际起伏网格及新材质，因此是这两块展示地面的对比，不是完整游戏的性能对比。

| 展示地面／镜头尺寸 | GPU 中位数 | GPU P95 |
| --- | --- | --- |
| 旧版平地，12 | 0.603 ms | 0.648 ms |
| 新样区，12 | 1.193 ms | 1.201 ms |
| 新样区，8 | 0.795 ms | 0.801 ms |
| 新样区，20 | 1.197 ms | 1.352 ms |
| 新样区，40 | 0.972 ms | 0.984 ms |

恢复全部云更新后，独立样区本机约 165 FPS，云更新约 20 Hz；这些数值受当前设备及 VSync 条件约束。一次场景进入测得约 373 ms，包含资源读取、地形生成与格线准备，不作为持续帧耗时。未开展完整棋盘接入、其他显卡或 Godot 4.6.1 的运行验证。原始测试脚本、帧序列和日志是本机产物，不随游戏资产共享；本文件保留了条件和实测结果。
